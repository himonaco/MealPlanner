MealPlanner — MVP

This repo will contain the Meal Planner iOS app (Swift + SwiftUI).

Goals (MVP):
- Daily Telegram dinner suggestions (3 recipes) tailored to household preferences
- Pantry model and shopping list generation
- Simple settings: household size, dietary preferences, allergies, message time

Development
- Branching: feature/* for work, PRs into main
- CI: GitHub Actions will build and run tests (configured later)

To start: open Xcode and create a new SwiftUI iOS app target named MealPlanner, or run the provided scaffolding script.
